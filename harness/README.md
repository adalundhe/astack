# astack packages

Generated by `python3 scripts/build.py` from the source at the repository root. Don't edit these folders by hand.

- `claude-code/` is the Claude Code plugin, listed in `.claude-plugin/marketplace.json`.
- `cursor/` is the Cursor / Cursor CLI plugin, listed in `.cursor-plugin/marketplace.json`.
- `codex/` is the Codex plugin, listed in `.agents/plugins/marketplace.json`.
- `antigravity/` is the native Antigravity (`agy`) plugin with `plugin.json`, root `hooks.json`, and all four full agents (`astack-lead`, `astack-worker`, `astack-reviewer`, `astack-researcher`).
- `portable/` is the harness-agnostic Agent Skills bundle for Pi, Devin, and other Agent Skills hosts (zero Claude-specific syntax).
